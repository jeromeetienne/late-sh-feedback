# Directory Context: `/data`

## Purpose
Holds the data of this project, both the local copies downloaded from external sources and the small files curated by hand.

## Key Exports & Entry Points
- `feedback/`: Feedback text files downloaded from the "late-sh" GitHub repository. See `feedback/CONTEXT.md`.
- `identity/`: Hand-maintained mapping from the nicknames used in late.sh to the people behind them. See `identity/CONTEXT.md`.
- `ingestion/`: Tracks which commit of "late-sh" was last read when publishing GitHub issues. See `ingestion/CONTEXT.md`.

## Local Rules & Boundaries
- Downloaded files are generated by scripts in `../scripts` — do not hand-edit their content, re-run the matching script instead. This applies to `feedback/`.
- Curated files are hand-maintained and no script may overwrite them. This applies to `identity/`, and each such folder must say so in its own `CONTEXT.md`.
- `ingestion/` is a third case: hand-initialized once, then maintained by the `/update-late-sh-issues` skill, not by a person and not by `npm run import:feedback`.
