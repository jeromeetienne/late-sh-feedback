# Directory Context: `/data`

## Purpose
Holds local, read-only copies of data downloaded from external sources for this project.

## Key Exports & Entry Points
- `feedback/`: Feedback text files downloaded from the "late-sh" GitHub repository. See `feedback/CONTEXT.md`.

## Local Rules & Boundaries
- Files under this folder are generated by scripts in `../scripts` — do not hand-edit their content, re-run the matching script instead.
