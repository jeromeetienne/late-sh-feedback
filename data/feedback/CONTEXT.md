# Directory Context: `/data/feedback`

## Purpose
Feedback text files downloaded from the "feedback" folder of the "mpiorowski/late-sh" GitHub repository, to be sorted out into bugs and suggestions for late.sh.

## Key Exports & Entry Points
- `bugs.txt`: Bug reports feedback, as downloaded from the "late-sh" GitHub repository.
- `suggestions.txt`: Suggestions feedback, as downloaded from the "late-sh" GitHub repository.

## Local Rules & Boundaries
- Do not hand-edit `bugs.txt` or `suggestions.txt` — regenerate them with `npm run import:feedback` instead.
